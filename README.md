# DBMS Lab Programs

SQL/DBMS laboratory programs completed as part of BCA coursework.

## Topics Covered

- Employee table creation
- INSERT, SELECT and UPDATE queries
- NULL and DISTINCT
- ALTER TABLE and commission calculation
- LIKE conditions and sorting
- String functions: `UPPER()`, `LOWER()`, `LENGTH()`, `INSTR()`, `SUBSTR()`
- Email username and domain extraction
- Job title updates and filtering
- Date functions: `SYSDATE`, `MONTHS_BETWEEN()`, `ADD_MONTHS()`, `NEXT_DAY()`, `LAST_DAY()`
- Date formatting using `TO_CHAR()`
- Employee tenure and anniversary queries

The SQL syntax in this lab is written for **Oracle SQL / Oracle Database**.
